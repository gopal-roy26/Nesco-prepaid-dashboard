# নেসকো প্রিপেইড ব্যালেন্স ড্যাশবোর্ড

## এটা কীভাবে কাজ করে
- `backend/main.py` — একটা FastAPI সার্ভার, যেটা `nesco-cli` (pip প্যাকেজ `nesco`) কল করে
  NESCO-র সার্ভার থেকে সরাসরি ব্যালেন্স, গ্রাহকের তথ্য, রিচার্জ হিস্ট্রি ও মাসিক ব্যবহার আনে,
  তারপর JSON বানিয়ে দেয়।
- `frontend/index.html` — একটা স্ট্যান্ডঅ্যালোন HTML ড্যাশবোর্ড, যেটা ব্রাউজারে খুলে
  ব্যাকএন্ডকে কল করে ফলাফল দেখায়।

`nesco` লাইব্রেরিটা NESCO-র নিজস্ব টুল না — একজন ডেভেলপার (mdminhazulhaque) এটা বানিয়েছেন
এবং MIT লাইসেন্সে ওপেন সোর্স করেছেন। ব্যবহারের আগে এই বিষয়টা মাথায় রাখুন এবং
নিজ দায়িত্বে ব্যবহার করুন।

## চালানোর ধাপ

### ১. ব্যাকএন্ড
```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows এ: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```
সার্ভার চালু হলে `http://localhost:8000/health` এ গিয়ে `{"status":"ok"}` দেখবেন।

### ২. ফ্রন্টএন্ড
`frontend/index.html` ফাইলটা সরাসরি ব্রাউজারে ডাবল-ক্লিক করে খুলুন (কোনো সার্ভার লাগবে না)।
মিটার/কনজিউমার নম্বর দিয়ে "চেক করুন" চাপুন।

## কেন দুটো আলাদা অংশ (ব্যাকএন্ড + ফ্রন্টএন্ড) দরকার
ব্রাউজার থেকে সরাসরি `customer.nesco.gov.bd`-তে JavaScript দিয়ে রিকোয়েস্ট পাঠানো যায় না —
ব্রাউজারের CORS নিরাপত্তা নীতি অন্য ডোমেইনে ক্রস-অরিজিন রিকোয়েস্ট আটকে দেয়, যদি না ওই
সার্ভার নিজে অনুমতি দেয়। তাই মাঝখানে একটা নিজের ব্যাকএন্ড (Python) লাগে, যেটা সার্ভার-সাইড
থেকে ডেটা এনে ব্রাউজারকে normal JSON রেসপন্স দেয়।

## সীমাবদ্ধতা ও ঝুঁকি
- এটা একটা আনঅফিসিয়াল/থার্ড-পার্টি টুলের উপর নির্ভরশীল; NESCO তাদের সার্ভারের গঠন বদলালে
  এটা কাজ করা বন্ধ করে দিতে পারে।
- অনেকবার দ্রুত রিকোয়েস্ট পাঠালে NESCO-র সার্ভার থেকে সাময়িকভাবে ব্লক হতে পারেন —
  তাই backend-এ ১২০ সেকেন্ডের একটা ছোট cache রাখা হয়েছে।
- শুধু নিজের মিটার নম্বর দিয়ে ব্যবহার করুন।

## পরের ধাপ (ইচ্ছা করলে যোগ করতে পারেন)
- একাধিক মিটার সেভ করে রাখা (localStorage-এর বদলে ব্যাকএন্ডে ছোট JSON ফাইলে)
- নির্দিষ্ট ব্যালেন্সের নিচে নামলে নোটিফিকেশন
- মাসিক ব্যবহারের একটা বার-চার্ট
